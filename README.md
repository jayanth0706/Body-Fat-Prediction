# Body Fat Prediction using Machine Learning 🧠💪

This project aims to accurately predict a person's body fat percentage using various body measurements and machine learning models. The primary goal is to create a predictive model that can help in health assessment and personalized fitness planning.

---

## 📖 About the Project

Body fat is a key health indicator. Traditional methods to measure body fat (like underwater weighing or DXA scans) are costly and inconvenient. This project uses a dataset of body measurements to predict body fat percentage using supervised machine learning models.

Key objectives:
- Analyze and clean the dataset.
- Apply exploratory data analysis (EDA).
- Train various regression models.
- Evaluate and compare model performances.

---

## 📊 Dataset

- **Source**: [Body Fat Dataset](https://www.kaggle.com/datasets)
- **Attributes**: Includes age, weight, height, abdomen circumference, and other body measurements.
- **Target Variable**: Body fat percentage.
